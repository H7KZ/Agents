# Code of conduct

Be respectful and constructive. No harassment, discrimination or personal attacks. Assume good faith, keep
feedback about the work, and help newcomers. Maintainers may remove comments, close issues and block people who
do not follow this. Report problems through GitHub (contact the repository owner privately).

This is adapted in spirit from the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
